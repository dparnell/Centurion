// The Centurion bootstrap PROM, 512 bytes at physical 0x3fc00.
//
// The CPU comes out of reset fetching from 0x3fd00, which is offset 0x100 here
// and holds JMP 0xfc00 - virtual 0xfc00 translating, through the top page of
// the map, back to the start of this ROM. It then tests sense switch 1 with
// BS1: set, it jumps to 0x8001 and the diag board takes over; clear, it
// configures the MUX and boots from disk.
//
// Recovered from the boot PROM image embedded in Meisaka's emulator, in
// Emulators/Meisaka_Ren/Centurion_files/cen.js in the Nakazoto
// CenturionComputer repository. It is stored there base64 encoded and with a
// scrambled address map; the loader inverts the address and permutes its bits
// by remap = [0,1,2,3,4,8,5,6,7], so image[a] = raw[remap(a ^ 511)]. This file
// is the descrambled result, in plain address order.
